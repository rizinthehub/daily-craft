# Contributing to Daily Craft

Thank you for your interest in contributing! This guide will help you make meaningful, daily contributions.

## 🎯 Contribution Philosophy

Every commit should:
- ✅ Add genuine value
- ✅ Be well-documented
- ✅ Follow naming conventions
- ✅ Include working code/examples

## 📝 Daily Contribution Checklist

Before committing, ask yourself:

- [ ] Is this content genuinely useful?
- [ ] Is the code properly formatted?
- [ ] Is there adequate documentation?
- [ ] Does the file follow naming conventions?
- [ ] Is this something I'd reference again?

## 📁 File Naming Conventions

| Category | Format | Example |
|----------|--------|---------|
| Notes | `YYYY-MM-DD-topic.md` | `2026-08-01-typescript-interfaces.md` |
| Snippets | `feature-name.ts` | `object-helpers.ts` |
| Algorithms | `algorithm-name.ts` | `merge-sort.ts` |
| Utilities | `utility-name.ts` | `http-client.ts` |
| References | `name.json` | `git-commands.json` |
| Journals | `YYYY-MM-DD.md` | `2026-08-01.md` |

## 💬 Commit Message Format

```
<type>: <short description>

[optional body with more details]
```

### Types

| Type | Use For |
|------|---------|
| `docs` | Documentation, notes, readmes |
| `feat` | New code snippets, algorithms |
| `util` | Utility functions, helpers |
| `ref` | JSON references, data files |
| `fix` | Bug fixes, corrections |
| `refactor` | Improving existing code |
| `journal` | Daily journal entries |
| `chore` | Maintenance, config updates |

### Examples

```bash
git commit -m "docs: add note on TypeScript interfaces"
git commit -m "feat: implement merge sort algorithm"
git commit -m "util: add array chunk helper function"
git commit -m "ref: add REST API status codes reference"
git commit -m "journal: day 5 - learned about closures"
```

## 🔄 Daily Workflow

1. **Morning**: Review what you learned yesterday
2. **During the day**: Take notes on new concepts
3. **Evening**: Add your daily contribution
   - A note from today's learning
   - A useful code snippet
   - An algorithm implementation
   - A journal entry

## ⚡ Quick Commands

```bash
# Check what changed
git status

# Add all changes
git add .

# Add specific file
git add notes/2026-08-01-topic.md

# Commit with message
git commit -m "type: description"

# Push to GitHub
git push

# View contribution history
git log --oneline
```

## 💡 Tips for Consistency

1. **Set a daily reminder** - Pick a specific time
2. **Start small** - Even one line counts
3. **Batch process** - Keep notes during the day
4. **Review weekly** - Reflect on your progress
5. **Make it enjoyable** - Work on topics you're interested in

---

*Remember: Consistency beats perfection. Make it count, every single day.*
