## 🎯 Purpose

**Daily Craft** is a lightweight repository with one mission: **maintain a consistent daily GitHub contribution streak through meaningful, incremental commits**.

Every entry is intentional. Every file adds value. Over time, this becomes your personal developer knowledge base—reflecting continuous learning and professional growth.

---

## 📁 Repository Structure

```
daily-craft/
├── notes/           # Programming concepts & learning notes
├── snippets/        # Reusable TypeScript code snippets
├── algorithms/      # Algorithm implementations
├── utilities/      # Developer utility functions
├── references/     # JSON reference data & cheatsheets
├── journals/       # Daily learning journals
└── docs/           # Project documentation
```

---

## 🚀 Quick Start

### Making Your Daily Entry

1. **Pick a category** from above
2. **Add or update** a relevant file
3. **Commit with purpose:**

```bash
git add .
git commit -m "docs: add note on [topic]"
git push
```

### Daily Entry Templates

| Category | File Naming | Commit Style |
|----------|-------------|--------------|
| `notes/` | `YYYY-MM-DD-topic.md` | `docs: add note on [topic]` |
| `snippets/` | `feature-name.ts` | `feat: add [feature] snippet` |
| `algorithms/` | `algorithm-name.ts` | `algo: implement [algorithm]` |
| `utilities/` | `utility-name.ts` | `util: add [utility] function` |
| `references/` | `reference-name.json` | `ref: add [reference] data` |
| `journals/` | `YYYY-MM-DD.md` | `journal: day [number] notes` |

---

## 📝 Contribution Guidelines

### ✅ Do

- Add genuinely useful content
- Update and improve existing entries
- Fix typos and improve documentation
- Share real learning from the day

### ❌ Don't

- Create placeholder/empty files
- Add unrelated content
- Commit without checking the code makes sense

## 💡 Ideas for Daily Contributions
